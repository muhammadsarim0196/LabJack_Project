# LabJack_Project
 C++ project for Labjack T7 pro having CB37 extension that is connected through the mux80 extender and a R4D3C32 relay board on a separate serial port 'COM9' via usb to rs485 that logs the data from labjack using influxdB. This code also hosts a webpage for configuration of the set point values for temperature that triggers the relay output.
